# 따릉이 수요예측 학습용 리포

서울시 공공자전거 '따릉이' 대여 수요예측을 주제로 데이터 분석 및 머신러닝을 연습하는 학습용 리포입니다.

## 구조

```
notes/               # 학습 중 정리하는 메모 (한글 파일명)
bike-demand/
  data/
    raw/             # 원본 데이터 (git 추적 안 함)
    processed/       # 전처리된 데이터 (git 추적 안 함)
  notebooks/         # 탐색 및 실험용 노트북
  src/                # 재사용 가능한 코드 (전처리, 학습, 평가 등)
  outputs/
    figures/          # 분석 결과 그래프 등 산출물
```

## 사용 언어

- 코드/파일명: 영문
- notes 폴더 마크다운 파일명: 한글
- 응답/주석: 한국어
