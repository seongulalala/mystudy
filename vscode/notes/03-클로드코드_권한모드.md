# Claude Code 권한 모드

## 차이 요약

```text
Manual
→ 작업은 하되 하나씩 확인

Edit automatically
→ 파일 편집은 자동

Plan
→ 먼저 어떻게 작업할지 계획부터 확인

Auto
→ 대부분 자동, 위험한 작업만 확인
```

## Manual

* 파일 수정이나 실행이 필요할 때 하나씩 승인받음
* 직접 통제하면서 작업할 때 사용

## Edit automatically

* 선택한 텍스트나 파일 편집은 자동 수행
* 터미널 실행 등 다른 작업은 별도 확인이 필요할 수 있음
* 코드 수정 위주 작업에 적합

## Plan

* 먼저 프로젝트를 조사하고 작업 계획을 제시
* 계획 승인 전에는 실제 수정하지 않음

계획 확인 후 선택:

```text
Yes, and auto-accept
→ 계획 승인 + 이후 수정 자동 승인

Yes, and manually approve edits
→ 계획 승인 + 실제 수정은 하나씩 확인

No, keep planning
→ 실행하지 않고 계획 계속 수정
```

## Auto

* 안전하다고 판단한 작업은 자동 수행
* 위험하거나 중요한 작업은 중단하고 확인
* 반복 작업에 편리함

## 사용 기준

* 처음 보는 코드 / 큰 수정 → `Plan`
* 수정 내용을 하나씩 확인 → `Manual`
* 파일 편집 위주 → `Edit automatically`
* 익숙한 반복 작업 → `Auto`
