# Claude Code 기초

## 일반 채팅과의 차이

* 일반 채팅: 사용자가 전달한 내용에 답변
* Claude Code: 프로젝트 파일을 탐색하고 수정하거나 명령을 실행할 수 있음

## 기본 작업 흐름

```text
요청 → 파일 탐색 → 계획 → 수정 → 실행 → 검증
```

요청에 따라 탐색이나 설명까지만 수행할 수도 있음.

## 핵심 개념

* **작업 폴더:** Claude가 파일 탐색을 시작하는 기준 위치
* **컨텍스트:** Claude가 답변에 사용하는 대화와 파일 정보
* **도구 사용:** 파일 읽기·수정, 터미널 명령 실행
* **권한:** Claude가 수행할 수 있는 작업 범위
* **검증:** Claude의 작업 결과를 사용자가 확인하는 과정

## 요청 범위 지정

```text
현재 작업 폴더의 구조를 확인해줘.
파일을 생성·수정·삭제하지 마.
데이터 파일은 열지 마.
```

요청에는 다음 내용을 명확히 적는 것이 좋음.

* 확인할 대상
* 수정 가능 여부
* 실행 가능 여부
* 열면 안 되는 파일
* 원하는 결과 형식


## 주의점

* Claude가 확인한 사실과 추측을 구분하도록 요청
* 프로젝트 전체를 불필요하게 탐색하지 않도록 범위 제한
* 파일 수정이 필요 없는 작업에는 명확하게 수정 금지 지시
* 답변에서 실제로 읽은 파일을 확인
