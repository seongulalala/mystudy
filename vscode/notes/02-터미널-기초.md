# VS Code 터미널 기초

## 위치와 목록 확인

```powershell
pwd
```

* 현재 터미널 경로 확인

```powershell
ls
```

* 현재 폴더의 파일과 하위 폴더 확인

## 폴더 이동

```powershell
cd bike-demand
```

* 지정한 폴더로 이동

```powershell
cd ..
```

* 상위 폴더로 이동

## 파일과 폴더 생성

```powershell
New-Item practice.md -ItemType File
ni practice.md -ItemType File
```

* 새 파일 생성
* `ni`: 짧게 사용하는 명령어

```powershell
New-Item terminal-practice -ItemType Directory
mkdir terminal-practice
```

* 새 폴더 생성



## 파일 내용 저장과 확인

```powershell
"# 터미널 연습" | Out-File practice.md -Encoding utf8
```

* 문자열을 UTF-8 형식으로 파일에 저장
* `|`: 왼쪽 결과를 오른쪽 명령어로 전달

```powershell
Get-Content practice.md
gc practice.md
```

* 파일 내용 출력
* `gc`: 짧게 사용하는 명령어

## 이름 변경

```powershell
Rename-Item practice.md terminal-basic.md
ren practice.md terminal-basic.md
```

* 파일 또는 폴더 이름 변경
* `ren`, `rni`: 짧게 사용하는 명령어

## 파일과 폴더 삭제

```powershell
Remove-Item terminal-basic.md
rm terminal-basic.md
```

* 파일 삭제
* `rm`, `ri`: 짧게 사용하는 명령어

```powershell
Remove-Item terminal-practice
rmdir terminal-practice
```

* 빈 폴더 삭제

```powershell
Remove-Item terminal-practice -Recurse
rm terminal-practice -Recurse
```

* 내부 파일과 하위 폴더까지 함께 삭제
* `-Recurse`: 하위 항목까지 처리

## 핵심 개념

* **절대 경로:** 드라이브부터 시작하는 전체 경로
* **상대 경로:** 현재 위치를 기준으로 작성한 경로
* **`-ItemType File`:** 파일로 생성
* **`-ItemType Directory`:** 폴더로 생성
* **`-Encoding utf8`:** UTF-8 형식으로 저장
* **`-Recurse`:** 하위 파일과 폴더까지 처리

## 주의점

* 명령 실행 전 `pwd`와 `ls`로 현재 위치 확인
* 공백이 있는 경로는 따옴표로 감싸기
* `Remove-Item` 실행 전 삭제 경로 확인
* `Out-File`은 기존 내용을 덮어쓸 수 있음
