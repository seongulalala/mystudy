## 1. VS Code 단축키

### 필수 (매일 씀)

| 단축키 | 기능 | 비고 |
|---|---|---|
| `F1` | 명령 팔레트 | `Ctrl+Shift+P`와 동일. 한글 IME 충돌 시 이걸로 |
| `Ctrl+P` | 파일 빠른 열기 | 파일명 일부만 쳐도 됨 |
| `` Ctrl+` `` | 터미널 토글 | |
| `Ctrl+B` | 사이드바 접기 | 화면 좁을 때 |
| `Ctrl+S` | 저장 | |
| `Ctrl+/` | 주석 토글 | 선택 영역 전체 가능 |

### 편집 (분석 코드 쓸 때 체감 큼)

| 단축키 | 기능 | 언제 쓰나 |
|---|---|---|
| `Ctrl+D` | 같은 단어 다중 선택 | 컬럼명 일괄 변경 |
| `Alt+Shift+↓` | 현재 줄 복제 | 비슷한 전처리 줄 반복할 때 |
| `Alt+↑` / `Alt+↓` | 줄 위아래 이동 | 처리 순서 바꿀 때 |
| `Shift+Alt+F` | 코드 자동 정렬 | 커밋 전 습관화 |
| `Ctrl+Shift+K` | 현재 줄 삭제 | |
| `Alt+클릭` | 커서 여러 개 추가 | 여러 위치 동시 편집 |

### 탐색

| 단축키 | 기능 |s
|---|---|
| `Ctrl+F` | 현재 파일 검색 |
| `Ctrl+Shift+F` | 전체 폴더 검색 |
| `Ctrl+H` | 찾아 바꾸기 |
| `F12` | 함수 정의로 이동 |
| `Alt+←` | 이전 위치로 복귀 |

### 노트북 (.ipynb)

| 단축키 | 기능 |
|---|---|
| `Shift+Enter` | 셀 실행 + 다음 셀 |
| `Ctrl+Enter` | 셀 실행 (제자리) |
| `Esc` → `A` / `B` | 위/아래 셀 추가 |
| `Esc` → `D` `D` | 셀 삭제 |
| `Esc` → `M` / `Y` | 마크다운 / 코드 셀 전환 |

## 2. 트러블슈팅 기록

### `Ctrl+Shift+P` 안 먹힘

- **원인**: 윈도우 입력 언어 전환 핫키와 충돌
- **임시 해결**: `F1` 사용
- **근본 해결**: 설정 → 시간 및 언어 → 입력 → 고급 키보드 설정 → 입력 언어 핫키 → "입력 언어 간 전환" 할당 해제
- **충돌 확인법**: `Ctrl+K` `Ctrl+S` → 키보드 단축키 창에서 해당 키 검색

## 3. Claude Code 확장 설치

- 정식 확장 ID: `anthropic.claude-code` (게시자 Anthropic, 인증 배지)
- 유사 확장 다수 존재 (Claudix, Cline 등) — 서드파티이므로 회사 코드에 사용 금지

```bash
code --install-extension anthropic.claude-code
code --list-extensions | grep -i claude
```

- 로그인: 유료 Claude 구독(Pro/Max/Team/Enterprise) 또는 Console 계정 필요
- 회사가 Bedrock/Vertex/Foundry 경유 시 `~/.claude/settings.json` 별도 설정 필요 → 입사 후 확인
