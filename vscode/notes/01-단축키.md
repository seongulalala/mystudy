# VS Code 단축키

## 기본

| 단축키 | 기능 |
|---|---|
| `F1` | 명령 팔레트 열기 |
| `Ctrl+P` | 파일 빠르게 열기 |
| `` Ctrl+` `` | 터미널 열기/닫기 |
| `Ctrl+B` | 사이드바 열기/닫기 |
| `Ctrl+S` | 저장 |
| `Ctrl+/` | 주석 처리/해제 |

## 검색

| 단축키 | 기능 |
|---|---|
| `Ctrl+F` | 현재 파일 검색 |
| `Ctrl+Shift+F` | 전체 프로젝트 검색 |
| `Ctrl+H` | 찾아 바꾸기 |

## 편집

| 단축키 | 기능 |
|---|---|
| `Ctrl+D` | 같은 단어 추가 선택 |
| `Alt+↑` / `Alt+↓` | 현재 줄 이동 |
| `Alt+Shift+↓` | 현재 줄 복제 |
