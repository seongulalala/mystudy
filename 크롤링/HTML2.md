# HTML 요소(Element) 핵심 정리

---

## 1. 문서 기본 구조 (필수)

| 요소 | 역할 |
|------|------|
| `<html>` | 문서 전체를 감싸는 최상위(루트) 요소. 하나만 존재 |
| `<head>` | 문서 정보(제목, 스타일 등)를 담는 영역. 화면에 안 보임 |
| `<body>` | 실제 화면에 보이는 본문 영역 |

```html
<html>
  <head> ← 눈에 안 보이는 정보 </head>
  <body> ← 눈에 보이는 내용 </body>
</html>
```

---

## 2. head 안에 들어가는 요소

| 요소 | 역할 | 예시 |
|------|------|------|
| `<title>` | 브라우저 탭에 뜨는 문서 제목 | `<title>네이버</title>` |
| `<meta>` | 문서 정보 (인코딩, 설명 등) | `<meta charset="UTF-8">` |
| `<link>` | 외부 파일 연결 (CSS 등) | |
| `<script>` | 자바스크립트 삽입 | |
| `<style>` | CSS를 직접 작성할 때 | |

> 크롤링할 때 `<meta>` 태그에서 페이지 설명이나 키워드를 뽑는 경우가 많음

---

## 3. 섹션 요소 (페이지 구역 나누기)

| 요소 | 역할 | 쉽게 말하면 |
|------|------|------------|
| `<header>` | 페이지 상단 영역 | 로고, 메뉴가 있는 위쪽 |
| `<nav>` | 메뉴/네비게이션 | 메뉴 모음 |
| `<main>` | 핵심 콘텐츠 영역 | 페이지의 본론 |
| `<section>` | 주제별 구역 | 장/절 구분 |
| `<article>` | 독립적인 콘텐츠 | 뉴스 기사 하나, 블로그 글 하나 |
| `<aside>` | 본문과 관련 적은 영역 | 사이드바, 광고 |
| `<footer>` | 페이지 하단 영역 | 저작권, 연락처 |
| `<h1>`~`<h6>` | 제목 (1이 가장 큼) | 글 제목, 소제목 |

---

## 4. 그룹 요소 (콘텐츠 묶기) ⭐ 크롤링에서 제일 많이 봄

| 요소 | 역할 | 쉽게 말하면 |
|------|------|------------|
| `<div>` | 블록 단위로 묶기 | **만능 상자** (레이아웃용) |
| `<p>` | 문단(paragraph) | 글 한 단락 |
| `<ul>` | 순서 없는 목록 | · 항목1 · 항목2 |
| `<ol>` | 순서 있는 목록 | 1. 항목1  2. 항목2 |
| `<li>` | 목록의 각 항목 | ul, ol 안에 들어감 |
| `<hr>` | 수평선 (단독 요소) | 구분선 |

> `<div>`는 크롤링할 때 거의 매번 만남. 대부분의 웹사이트가 div로 구역을 나눔

---

## 5. 텍스트 요소 ⭐ 크롤링에서 자주 만남

| 요소 | 역할 | 쉽게 말하면 |
|------|------|------------|
| `<a>` | 하이퍼링크 | 클릭하면 이동하는 링크 |
| `<span>` | 인라인 텍스트 묶기 | div의 인라인 버전 |
| `<strong>` | 중요 텍스트 (굵게) | **굵은 글씨** |
| `<em>` | 강조 텍스트 (기울임) | *기울임 글씨* |
| `<br>` | 줄바꿈 (단독 요소) | 엔터 한 번 |
| `<code>` | 소스 코드 표현 | |

> `<a>`는 링크 크롤링의 핵심. href 속성에서 URL을 뽑아냄

---

## 6. 테이블 요소

| 요소 | 역할 |
|------|------|
| `<table>` | 표 전체 |
| `<thead>` | 표 머리(제목 행) |
| `<tbody>` | 표 본문 |
| `<tr>` | 행 (table row) |
| `<th>` | 제목 셀 |
| `<td>` | 내용 셀 (table data) |

## 7. 폼 요소 (사용자 입력)

| 요소 | 역할 |
|------|------|
| `<form>` | 입력 서식 영역 |
| `<input>` | 텍스트 입력, 체크박스, 라디오 등 |
| `<button>` | 버튼 |
| `<select>` | 드롭다운 목록 |
| `<option>` | select의 각 항목 |
| `<textarea>` | 여러 줄 입력 |
| `<label>` | 입력 서식의 이름표 |

---

## 8. 미디어/포함 요소

| 요소 | 역할 |
|------|------|
| `<img>` | 이미지 삽입 (단독 요소) |
| `<video>` | 동영상 삽입 |

| `<audio>` | 오디오 삽입 |
| `<iframe>` | 외부 페이지를 안에 삽입 |

---

## 핵심 요약: 크롤링할 때 제일 많이 보는 TOP 10

1. `<div>` — 거의 모든 구역
2. `<a>` — 링크 (href 속성에 URL)
3. `<span>` — 텍스트 묶기
4. `<p>` — 문단
5. `<img>` — 이미지 (src 속성에 이미지 경로)
6. `<table>`, `<tr>`, `<td>` — 표 데이터
7. `<ul>`, `<li>` — 목록
8. `<h1>`~`<h6>` — 제목
9. `<input>` — 검색창 등
10. `<meta>` — 페이지 정보
