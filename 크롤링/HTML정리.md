# HTML의 속성들

## 1. 핵심 요약

1. HTML 문서는 여러 요소(Element)로 구성되어 있다.

2. 대부분의 HTML 요소는 시작 태그(start tag)로 시작하고 종료 태그(end tag)로 끝난다.

3. 시작 태그에는 속성(Attribute)이 붙을 수 있다.

4. 시작 태그와 종료 태그 사이에는 텍스트 또는 다른 요소(child)가 들어갈 수 있다.

5. 하나의 요소가 child이면서 동시에 다른 요소의 parent가 될 수 있다.
   예) `table`은 `body`의 child이면서 `tr`의 parent가 될 수 있다.

6. 일부 요소는 종료 태그가 없는 형태로 사용된다.
   예) `img`, `input`, `meta`, `br`

---

## 1. 핵심 요약 예시

다음 HTML 코드를 기준으로 이해할 수 있다.

```html
<body>
  <table>
    <tr>
      <td>사과</td>
      <td>1,000원</td>
    </tr>
  </table>
</body>
```

### 1. HTML 문서는 여러 요소(Element)로 구성되어 있다

위 코드에는 다음과 같은 요소들이 있다.

| 요소        | 설명                   |
| --------- | -------------------- |
| `<body>`  | 화면에 보이는 본문 영역        |
| `<table>` | 표를 만드는 요소            |
| `<tr>`    | 표의 한 행(row)을 만드는 요소  |
| `<td>`    | 표의 한 칸(cell)을 만드는 요소 |

---

### 2. 각 요소는 시작 태그로 시작하고 종료 태그로 끝난다

예를 들어 `<table>` 요소는 다음과 같이 구성된다.

```html
<table>
  ...
</table>
```

| 구분    | 해당 부분      |
| ----- | ---------- |
| 시작 태그 | `<table>`  |
| 종료 태그 | `</table>` |

`td` 요소도 마찬가지다.

```html
<td>사과</td>
```

| 구분    | 해당 부분   |
| ----- | ------- |
| 시작 태그 | `<td>`  |
| 내용    | `사과`    |
| 종료 태그 | `</td>` |

---

### 3. 시작 태그에는 속성(Attribute)이 붙을 수 있다

예를 들어 다음과 같이 `class` 속성을 붙일 수 있다.

```html
<td class="product-name">사과</td>
<td class="price">1,000원</td>
```

| 구분                     | 설명              |
| ---------------------- | --------------- |
| `class="product-name"` | 상품명을 구분하기 위한 속성 |
| `class="price"`        | 가격을 구분하기 위한 속성  |

크롤링에서는 이런 속성을 이용해서 원하는 데이터만 찾을 수 있다.

```python
name = soup.select_one(".product-name").text
price = soup.select_one(".price").text
```

---

### 4. 시작 태그와 종료 태그 사이에는 텍스트 또는 다른 요소가 들어갈 수 있다

텍스트가 들어가는 경우:

```html
<td>사과</td>
```

다른 요소가 들어가는 경우:

```html
<td>
  <span class="price">1,000원</span>
</td>
```

여기서 `<td>` 안에 `<span>` 요소가 들어가 있다.

---

### 5. 하나의 요소가 child이면서 동시에 다른 요소의 parent가 될 수 있다

다음 구조를 보자.

```html
<body>
  <table>
    <tr>
      <td>사과</td>
    </tr>
  </table>
</body>
```

관계는 다음과 같다.

| 요소        | 관계                                 |
| --------- | ---------------------------------- |
| `<body>`  | `<table>`의 parent                  |
| `<table>` | `<body>`의 child이면서 `<tr>`의 parent  |
| `<tr>`    | `<table>`의 child이면서 `<td>`의 parent |
| `<td>`    | `<tr>`의 child                      |

구조로 보면 다음과 같다.

```text
body
 └── table
      └── tr
           └── td
```

## 2. 핵심 요약2

1. HTML 요소는 보통 시작 태그, 속성, 내용, 종료 태그로 구성된다.

2. 시작 태그에는 속성이 있을 수도 있고 없을 수도 있다.

3. 내용에는 텍스트나 다른 요소(child)가 있을 수도 있고 없을 수도 있다.

4. 일부 요소는 종료 태그나 내용이 없는 형태로 사용된다.
   예) `img`, `input`, `meta`, `br`

---

## 2. 핵심 요약2 예시

다음 HTML 코드를 기준으로 이해할 수 있다.

```html
<a href="https://www.naver.com" class="site-link">네이버로 이동</a>
```

### 1. HTML 요소는 보통 시작 태그, 속성, 내용, 종료 태그로 구성된다

위 코드를 나누면 다음과 같다.

| 구분    | 해당 부분                                                           |
| ----- | --------------------------------------------------------------- |
| 시작 태그 | `<a href="https://www.naver.com" class="site-link">`            |
| 속성    | `href="https://www.naver.com"`, `class="site-link"`             |
| 내용    | `네이버로 이동`                                                       |
| 종료 태그 | `</a>`                                                          |
| 요소 전체 | `<a href="https://www.naver.com" class="site-link">네이버로 이동</a>` |

---

### 2. 시작 태그에는 속성이 있을 수도 있고 없을 수도 있다

속성이 있는 경우:

```html
<p class="title">오늘의 뉴스</p>
```

| 구분    | 내용                  |
| ----- | ------------------- |
| 시작 태그 | `<p class="title">` |
| 속성    | `class="title"`     |
| 내용    | `오늘의 뉴스`            |
| 종료 태그 | `</p>`              |

속성이 없는 경우:

```html
<p>오늘의 뉴스</p>
```

| 구분    | 내용       |
| ----- | -------- |
| 시작 태그 | `<p>`    |
| 속성    | 없음       |
| 내용    | `오늘의 뉴스` |
| 종료 태그 | `</p>`   |

즉, 속성은 반드시 있어야 하는 것은 아니다.

---

### 3. 내용에는 텍스트나 다른 요소(child)가 있을 수도 있고 없을 수도 있다

내용이 텍스트인 경우:

```html
<p>안녕하세요</p>
```

| 구분 | 내용      |
| -- | ------- |
| 내용 | `안녕하세요` |

내용에 다른 요소가 들어간 경우:

```html
<p>가격은 <span class="price">10,000원</span>입니다.</p>
```

여기서 `<p>` 요소 안에는 텍스트와 `<span>` 요소가 함께 들어 있다.

| 구분       | 내용                                   |
| -------- | ------------------------------------ |
| 텍스트      | `가격은`, `입니다.`                        |
| child 요소 | `<span class="price">10,000원</span>` |

내용이 없는 경우:

```html
<div class="empty-box"></div>
```

이 경우 `<div>` 요소는 시작 태그와 종료 태그는 있지만, 그 사이에 내용이 없다.

---

### 4. 일부 요소는 종료 태그나 내용이 없는 형태로 사용된다

예를 들어 다음 요소들은 보통 종료 태그 없이 사용된다.

```html
<img src="cat.jpg" alt="고양이 사진">
<input type="text" placeholder="검색어를 입력하세요">
<meta charset="UTF-8">
<br>
```

| 요소        | 설명           |
| --------- | ------------ |
| `<img>`   | 이미지를 보여주는 요소 |
| `<input>` | 입력창을 만드는 요소  |
| `<meta>`  | 문서 정보를 담는 요소 |
| `<br>`    | 줄바꿈 요소       |

이런 요소들은 다른 텍스트를 감싸는 목적이 아니기 때문에 종료 태그가 없는 경우가 많다.

# HTML 요소(Element) 핵심 정리

## 1. 문서 기본 구조

| 요소       | 역할                                              |
| -------- | ----------------------------------------------- |
| `<html>` | 문서 전체를 감싸는 최상위(루트) 요소. 하나만 존재                   |
| `<head>` | 문서 정보, 제목, 스타일, meta 정보 등을 담는 영역. 화면에 직접 보이지 않음 |
| `<body>` | 실제 화면에 보이는 본문 영역                                |

```html
<html>
  <head>
    눈에 안 보이는 문서 정보
  </head>
  <body>
    눈에 보이는 내용
  </body>
</html>
```

---

## 2. 핵심 요소들 TOP 10

| 요소                        | 역할                                                  |
| ------------------------- | --------------------------------------------------- |
| `<div>`                   | 웹페이지에서 구역을 나눌 때 가장 많이 쓰이는 블록 요소                     |
| `<a>`                     | 링크 요소. `href` 속성에 이동할 URL이 들어감                      |
| `<span>`                  | 문장 안의 일부 텍스트를 묶는 인라인 요소                             |
| `<p>`                     | 문단을 나타내는 요소                                         |
| `<img>`                   | 이미지 요소. `src` 속성에 이미지 경로가 들어감                       |
| `<table>`, `<tr>`, `<td>` | 표 데이터를 만들 때 사용하는 요소                                 |
| `<ul>`, `<li>`            | 목록을 만들 때 사용하는 요소                                    |
| `<h1>`~`<h6>`             | 제목을 나타내는 요소. 숫자가 작을수록 큰 제목                          |
| `<input>`                 | 검색창, 입력창, 체크박스 등 사용자 입력을 받는 요소                      |
| `<meta>`                  | 페이지 정보, 문자 인코딩, 검색엔진 정보 등을 담는 요소. 보통 `<head>` 안에 있음 |

## 3. div와 span 차이

`div`와 `span`은 둘 다 요소를 묶을 때 사용한다.
하지만 사용 목적이 다르다.

| 구분  | `<div>`       | `<span>`              |
| --- | ------------- | --------------------- |
| 성격  | 블록 요소         | 인라인 요소                |
| 줄바꿈 | 줄바꿈됨          | 줄바꿈되지 않음              |
| 용도  | 큰 구역을 묶을 때 사용 | 문장 안의 일부 텍스트를 묶을 때 사용 |
| 느낌  | 박스            | 형광펜                   |

---

### div 예시

```html
<div>첫 번째 구역</div>
<div>두 번째 구역</div>
```

화면에는 보통 다음처럼 보인다.

```text
첫 번째 구역
두 번째 구역
```

`div`는 블록 요소이기 때문에 한 줄 전체를 차지하고 줄바꿈된다.

---

### span 예시

```html
<p>가격은 <span class="price">10,000원</span>입니다.</p>
```

화면에는 보통 다음처럼 보인다.

```text
가격은 10,000원입니다.
```

`span`은 인라인 요소이기 때문에 문장 안에서 일부 텍스트만 묶을 때 사용한다.

---

## 4. 문장 안의 일부를 묶는 이유

문장 안의 일부를 묶는 이유는 특정 부분만 따로 꾸미거나, 찾거나, 수정하기 위해서다.

예를 들어 다음 문장이 있다고 하자.

```html
<p>가격은 10,000원입니다.</p>
```

이 상태에서는 `10,000원`만 따로 다루기 어렵다.

그래서 다음처럼 `span`으로 가격 부분만 묶을 수 있다.

```html
<p>가격은 <span class="price">10,000원</span>입니다.</p>
```

이렇게 하면 `10,000원`만 따로 선택할 수 있다.

크롤링에서는 다음처럼 가져올 수 있다.

```python
price = soup.select_one(".price").text
```

즉, `span`은 문장 전체가 아니라 특정 부분만 따로 관리하기 위한 요소다.

# 크롤링 관점에서 HTML 보기

## 1. 화면에 보이는 것과 HTML 코드의 차이

웹사이트 화면에는 보통 텍스트, 이미지, 버튼만 보인다.

예를 들어 화면에는 다음처럼 보일 수 있다.

```text
무선 마우스
15,000원
상세보기
```

하지만 실제 HTML 코드는 다음처럼 되어 있을 수 있다.

```html
<div class="product">
  <span class="title">무선 마우스</span>
  <span class="price">15,000원</span>
  <a href="/product/100">상세보기</a>
</div>
```

화면에 직접 보이는 것은 다음과 같다.

| 화면에 보이는 내용 | HTML 위치                              |
| ---------- | ------------------------------------ |
| 무선 마우스     | `<span class="title">무선 마우스</span>`  |
| 15,000원    | `<span class="price">15,000원</span>` |
| 상세보기       | `<a href="/product/100">상세보기</a>`    |

반면에 화면에 직접 보이지 않지만 크롤링에서 중요한 정보는 다음과 같다.

| HTML 정보               | 의미             |
| --------------------- | -------------- |
| `class="product"`     | 상품 영역을 구분하는 속성 |
| `class="title"`       | 상품명을 구분하는 속성   |
| `class="price"`       | 가격을 구분하는 속성    |
| `href="/product/100"` | 상세 페이지 주소      |

---

## 2. 크롤링 예시

HTML 코드가 다음과 같다고 가정한다.

```html
<div class="product">
  <span class="title">무선 마우스</span>
  <span class="price">15,000원</span>
  <a href="/product/100">상세보기</a>
</div>
```

이 HTML에서 가져올 수 있는 정보는 다음과 같다.

| 가져올 데이터   | HTML 위치                              |
| --------- | ------------------------------------ |
| 상품명       | `<span class="title">무선 마우스</span>`  |
| 가격        | `<span class="price">15,000원</span>` |
| 상세 페이지 주소 | `<a href="/product/100">상세보기</a>`    |

Python에서는 다음처럼 가져올 수 있다.

```python
title = soup.select_one(".title").text
price = soup.select_one(".price").text
link = soup.select_one("a")["href"]

print(title)
print(price)
print(link)
```

결과는 다음과 같다.

```text
무선 마우스
15,000원
/product/100
```

## 3. 선택자 기본 개념

크롤링에서는 원하는 요소를 찾기 위해 선택자(selector)를 사용한다.

| 선택자          | 의미                     | 예시                 |
| ------------ | ---------------------- | ------------------ |
| `태그명`        | 특정 태그를 찾음              | `a`, `div`, `span` |
| `.class명`    | 특정 class를 가진 요소를 찾음    | `.price`           |
| `#id명`       | 특정 id를 가진 요소를 찾음       | `#content`         |
| `태그명.class명` | 특정 class를 가진 특정 태그를 찾음 | `span.price`       |

예시:

```html
<span class="price">15,000원</span>
```

위 HTML을 크롤링 관점에서 보면 다음과 같다.

| 구분        | 내용                       |
| --------- | ------------------------ |
| 요소        | `span`                   |
| 속성        | `class="price"`          |
| 화면에 보이는 값 | `15,000원`                |
| 크롤링 선택자   | `.price` 또는 `span.price` |

Python에서는 다음처럼 찾을 수 있다.

```python
price = soup.select_one(".price").text
```

## 한 줄 요약

HTML 요소는 웹페이지를 구성하는 부품이고, 속성은 그 부품을 설명하거나 구분하는 추가 정보다.

크롤링은 화면에 보이는 결과만 보는 것이 아니라, HTML 코드 안에서 원하는 요소와 속성을 찾아 데이터를 가져오는 작업이다.
