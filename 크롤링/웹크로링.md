# 크롤링
### 웹 크롤러
- 월드 와이드 웹을 탐색하는 프로그램
- 웹 크롤러가 하는 작업을 "웹 크롤링" or "스파이더링"

### 클라이언트와 서버
- 클라이언트 : 브라우저, 스마트폰, 노트북, 크롤링 등 서버에게 요청하는 주체(By HTTP)
- 서버 : 요청을 받는 사이트

### HTTP(HyperText Transfer Protocol)
- WWW 상에서 정보를 주고받을 수 있는 프로토콜

### HTTP 응답 코드
|코드|메시지|설명|
|--|---|---|
|2xx | 성공 | 요청에 따른 전송 성공|
|3xx | 이동 | 요청을 하는 주소가 틀렸다(바뀜)|
|403 | 금지 | 요청이 차단됨(금지)|
|404 | 못찾음 | 요청한 문서를 찾을 수 없음(오타 등)|
|405 | 머서드 허용 X | 요청 방식이 틀림|
|5xx | 서버 내부 오류 | 우리 서버 불나서 못 보냄|

 ### 크롤러 분류
 1. 상태(로그인 등)를 가지는지 여부
 2. 자바스크립트 실행 가능 여부
 3. 특정 / 불특정 사이트 대상인지 여부
