# python
설치된 라이브러리 목록보기  
- `pip list`

최신 버전 라이브러리 설치
- `pip install 라이브러리명`

지정 버전 라이브러리 설치
- `pip install 라이브러리명 ==버전번호`

라이브러리 삭제
- `pip uninstall 라이브러리명`

라이브러리 정보 보기
- `pip show 라이브러리명`
